# Как открыть приложение по ссылке из интернета (в т.ч. с айфона)

Это дополнительный, необязательный режим работы. По умолчанию приложение
работает **локально** (см. `README_FOR_ILYA.md`). Инструкция ниже — если вы
хотите открывать его с любого устройства (телефон, планшет) из любой точки
как обычный сайт.

## Почему это не может сделать сам ассистент

Я подготовил и проверил весь код: экран входа по паролю, Docker-сборку,
автоматический деплой через GitHub Actions. Но у рабочей среды, в которой я
выполняю команды, **нет доступа в общий интернет** — только к нескольким
служебным адресам (реестры пакетов и серверы Anthropic). Завести аккаунт на
хостинге и привязать к нему оплату могут только вы — это в любом случае
требует ваших личных данных, которых у меня нет и не должно быть.

Дальше — весь процесс должен занять 10–15 минут, большая часть — один раз.

## Что уже готово в репозитории

- `Dockerfile`, `.dockerignore`, `docker-entrypoint.sh` — контейнер сам
  применяет миграции и стартовые настройки при каждом запуске.
- `fly.toml` — конфигурация для хостинга **Fly.io** (поддерживает постоянный
  диск для файла базы данных — это важно, обычный «простой» хостинг для
  этого не подходит).
- Экран входа по паролю (`/login`) — активируется автоматически, если задана
  переменная окружения `APP_PASSWORD`. Без неё (как при локальном запуске)
  пароль не спрашивается.
- `.github/workflows/deploy.yml` — при пуше в репозиторий GitHub сам соберёт
  и выложит новую версию на Fly.io (без участия ассистента и этой рабочей
  среды — сборка идёт на серверах GitHub, у которых есть полный доступ в
  интернет).

## Шаг 1. Аккаунт на Fly.io и инструмент flyctl

На своём компьютере (не в этой сессии):

```bash
# macOS / Linux
curl -L https://fly.io/install.sh | sh

# Windows (PowerShell)
pwsh -Command "iwr https://fly.io/install.ps1 -useb | iex"
```

Затем:

```bash
fly auth signup    # если аккаунта ещё нет — откроется браузер
# или
fly auth login      # если аккаунт уже есть
```

Может попросить привязать карту — Fly даёт бесплатный лимит, для одного
небольшого личного приложения обычно укладывается в $0–5/мес.

## Шаг 2. Склонировать репозиторий и создать приложение

```bash
git clone <ссылка на ваш репозиторий>
cd -claude-test
git checkout claude/legal-practice-economics-oytqu9
```

Откройте `fly.toml` и замените `app = "legal-practice-economics"` на своё
уникальное имя, например `app = "ivan-legal-practice-2026"` (имя должно
быть свободно — Fly подскажет, если занято). Регион (`primary_region`)
можно оставить `waw` (Варшава) или заменить на ближайший к вам — список
командой `fly platform regions`.

```bash
fly apps create ivan-legal-practice-2026   # ваше имя из fly.toml
fly volumes create legal_practice_data --size 1 --region waw
```

## Шаг 3. Пароль и секрет для входа

```bash
fly secrets set APP_PASSWORD='придумайте-надёжный-пароль' \
                 APP_SECRET="$(openssl rand -hex 32)"
```

`APP_PASSWORD` — именно этот пароль вы будете вводить на айфоне при входе на
сайт. `APP_SECRET` — техническая строка для подписи сессии, использовать
именно эту команду не обязательно, важно чтобы значение было длинным и
случайным.

## Шаг 4. Первый деплой вручную

```bash
fly deploy
```

Первая сборка займёт несколько минут. В конце Fly покажет адрес вида:

```
https://ivan-legal-practice-2026.fly.dev
```

Откройте его — увидите экран входа, введите пароль из шага 3.

## Шаг 5 (необязательно). Автодеплой при каждом обновлении кода

Чтобы дальнейшие изменения выкладывались сами, без ручного `fly deploy`:

```bash
fly tokens create deploy -x 999999h
```

Скопируйте токен. В GitHub: репозиторий → **Settings → Secrets and
variables → Actions → New repository secret**, имя `FLY_API_TOKEN`,
значение — токен из команды выше.

После этого при каждом пуше в ветку `claude/legal-practice-economics-oytqu9`
(или `main`) GitHub сам соберёт и выложит новую версию. Запустить вручную
можно на вкладке **Actions → Деплой на Fly.io → Run workflow**.

## Как открыть на iPhone

Просто откройте ссылку `https://<ваше-имя-приложения>.fly.dev` в Safari,
введите пароль. Можно нажать «Поделиться → На экран «Домой»» — появится
иконка, как у обычного приложения.

## Важно про приватность в этом режиме

Как только приложение открыто из интернета — данные (в т.ч. потенциально
медицинские) физически лежат на сервере Fly.io, а не только на вашем
компьютере. Это осознанный компромисс ради доступа с телефона откуда
угодно. Рекомендации:

- используйте надёжный пароль в `APP_PASSWORD`, не сообщайте его посторонним;
- не отключайте `force_https` в `fly.toml` (соединение должно быть
  зашифровано);
- продолжайте пользоваться обезличенными кодами клиентов вместо ФИО;
- регулярно скачивайте резервную копию (Настройки → Данные и резервные
  копии) себе на устройство.

## Если что-то не получилось

- `fly deploy` ругается на занятое имя — поменяйте `app` в `fly.toml` и
  повторите `fly apps create`.
- Сайт открывается, но база данных каждый раз пустая — том (volume) не
  подключился; проверьте `fly volumes list` и что `destination` в
  `fly.toml` (`/app/data`) совпадает с тем, что использует приложение.
- Забыли пароль — задайте новый: `fly secrets set APP_PASSWORD='новый-пароль'`.
