# Стоимость юруслуг

Персональное мобильное приложение для расчёта стоимости юридических услуг, ведения клиентов, дел, расчётов и платежей. Первая версия — только локально, на одном iPhone через Expo Go, без сервера и облака.

## Быстрый старт

```bash
cd legal-fee-calculator
npm install
npx expo start
```

Затем отсканируйте QR-код камерой iPhone (компьютер и iPhone должны быть в одной Wi-Fi-сети) или из приложения Expo Go. Если LAN не работает:

```bash
npx expo start --tunnel
```

## Проверки

```bash
npm run typecheck   # проверка типов TypeScript
npm run lint        # линтер
npm test            # unit-тесты расчётного движка
```

## Архитектура

- `app/` — экраны и маршруты (Expo Router);
- `src/domain/` — типы и чистый расчётный движок (`engine.ts`, `selectors.ts`);
- `src/storage/` — репозитории AsyncStorage, миграции схемы и резервное копирование;
- `src/store/` — глобальное состояние приложения;
- `src/components/` — переиспользуемые компоненты интерфейса;
- `src/constants/` — начальные настройки, каталог услуг, подписи, тема;
- `src/utils/` — форматирование рублей, дат и чисел;
- `src/__tests__/` — тесты формул.

## Хранение данных

Данные хранятся локально на телефоне через AsyncStorage и не исчезают после закрытия приложения. Все денежные суммы — в целых рублях. Резервная копия экспортируется в один файл JSON (раздел «Настройки»).

## Ограничения первой версии

- один пользователь, без авторизации и облака;
- работает через Expo Go (без собственного native-кода и development build);
- данные живут только на этом устройстве — переносите их файлом резервной копии.
