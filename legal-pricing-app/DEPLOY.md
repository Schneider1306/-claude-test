# Как открыть калькулятор по ссылке из интернета (в т.ч. с айфона)

Это дополнительный, необязательный режим работы. По умолчанию приложение
работает **локально** (см. `README_FOR_ILYA.md`) — так проще и приватнее.
Инструкция ниже — если вы хотите открывать его с любого устройства из любой
точки, без включённого компьютера.

## Почему это не может сделать сам ассистент

Весь код подготовлен и проверен: экран входа по паролю, Docker-сборка,
автоматический деплой через GitHub Actions. Но у рабочей среды, в которой
выполняются мои команды, **нет доступа в общий интернет** — только к
npm-реестру. Завести аккаунт на хостинге и привязать к нему оплату можете
только вы — это в любом случае требует ваших личных данных.

Дальше — процесс занимает 10–15 минут, почти всё — один раз.

## Что уже готово в репозитории

- `Dockerfile`, `.dockerignore`, `docker-entrypoint.sh` — контейнер сам
  применяет миграции и стартовые настройки при каждом запуске.
- `fly.toml` — конфигурация для хостинга **Fly.io** (поддерживает постоянный
  диск для файла базы данных — обычный «простой» хостинг для этого не
  подходит).
- Экран входа по паролю (`/login`) — включается автоматически, если задана
  переменная окружения `APP_PASSWORD`. Без неё (как при локальном запуске)
  пароль не спрашивается, ничего не ломается.
- `.github/workflows/deploy-calculator.yml` — при пуше в ветку
  `claude/new-session-pa1hur` (в папке `legal-pricing-app`) GitHub сам
  соберёт и выложит новую версию на Fly.io.

## Шаг 1. Аккаунт на Fly.io и инструмент flyctl

На своём компьютере (не в этой сессии):

```bash
# macOS / Linux
curl -L https://fly.io/install.sh | sh

# Windows (PowerShell)
pwsh -Command "iwr https://fly.io/install.ps1 -useb | iex"
```

Затем:

```bash
fly auth signup    # если аккаунта ещё нет — откроется браузер
# или
fly auth login      # если аккаунт уже есть
```

Может попросить привязать карту — Fly даёт бесплатный лимит, для одного
небольшого личного приложения обычно укладывается в $0–5/мес (машина
автоматически «засыпает», когда никто не заходит).

## Шаг 2. Склонировать репозиторий и создать приложение

```bash
git clone <ссылка на ваш репозиторий>
cd -claude-test
git checkout claude/new-session-pa1hur
cd legal-pricing-app
```

Откройте `fly.toml` и замените `app = "legal-pricing-app"` на своё
уникальное имя, например `app = "ivan-legal-calc-2026"` (имя должно быть
свободно — Fly подскажет, если занято). Регион (`primary_region`) можно
оставить `waw` (Варшава) или заменить на ближайший к вам — список командой
`fly platform regions`.

```bash
fly apps create ivan-legal-calc-2026        # ваше имя из fly.toml
fly volumes create legal_pricing_data --size 1 --region waw
```

## Шаг 3. Пароль и секрет для входа

```bash
fly secrets set APP_PASSWORD='придумайте-надёжный-пароль' \
                 APP_SECRET="$(openssl rand -hex 32)"
```

`APP_PASSWORD` — это то, что вы будете вводить на экране входа. Держите его
в надёжном месте, `APP_SECRET` можно не запоминать — он просто должен быть
случайным.

## Шаг 4. Первый деплой вручную

```bash
fly deploy
```

Первая сборка займёт несколько минут. В конце Fly покажет адрес вида:

```
https://ivan-legal-calc-2026.fly.dev
```

Откройте его — увидите экран входа, введите пароль из шага 3.

## Шаг 5 (необязательно). Автодеплой при каждом обновлении кода

Чтобы дальнейшие изменения выкладывались сами, без ручного `fly deploy`:

```bash
fly tokens create deploy -x 999999h
```

Скопируйте токен. В GitHub: репозиторий → **Settings → Secrets and
variables → Actions → New repository secret**, имя `FLY_API_TOKEN`,
значение — токен из команды выше.

После этого при каждом пуше в ветку `claude/new-session-pa1hur` (в файлах
внутри `legal-pricing-app/`) GitHub сам соберёт и выложит новую версию.
Запустить вручную можно на вкладке **Actions → Деплой калькулятора на
Fly.io → Run workflow**.

## Как открыть на iPhone

Просто откройте вашу ссылку `https://<ваше-имя-приложения>.fly.dev` в
Safari, введите пароль. Можно нажать «Поделиться → На экран «Домой»» —
появится иконка, как у обычного приложения (то же самое PWA, что описано в
`README_FOR_ILYA.md`, только теперь работает без домашнего Wi-Fi).

## Важно про приватность в этом режиме

Как только приложение открыто из интернета — данные (в т.ч. коды клиентов и
суммы) физически лежат на сервере Fly.io, а не только на вашем компьютере.
Это осознанный компромисс ради доступа с телефона откуда угодно.
Рекомендации:

- используйте надёжный пароль в `APP_PASSWORD`, не сообщайте его посторонним;
- не отключайте `force_https` в `fly.toml` (соединение должно быть
  зашифровано);
- продолжайте пользоваться обезличенными кодами клиентов вместо ФИО (как и
  предусмотрено по умолчанию);
- регулярно делайте резервную копию (Настройки → «Экспорт базы в JSON») себе
  на устройство.

## Если что-то не получилось

- `fly deploy` ругается на занятое имя — поменяйте `app` в `fly.toml` и
  повторите `fly apps create`.
- Сайт открывается, но данные каждый раз пустые — том (volume) не
  подключился; проверьте `fly volumes list` и что `destination` в
  `fly.toml` (`/app/data`) совпадает с тем, что использует приложение.
- Забыли пароль — задайте новый: `fly secrets set APP_PASSWORD='новый-пароль'`.
- Хотите вернуться к чисто локальному режиму — просто не задавайте
  `APP_PASSWORD`: локальный запуск (`start-windows.bat`) как и раньше не
  спрашивает пароль.
