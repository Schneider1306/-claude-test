# Калькулятор стоимости юридических услуг — инструкция

Простая инструкция для запуска и повседневного использования программы.
Программа работает **только на вашем компьютере** — ничего не отправляется
в интернет, никаких сторонних сервисов. Все ваши расчёты хранятся в одном
файле на вашем диске.

## 1. Что нужно установить один раз

Программе нужен **Node.js** — бесплатная программа, без которой ничего не
запустится.

1. Откройте https://nodejs.org/
2. Скачайте версию **LTS** (рекомендованную).
3. Установите её, как обычную программу (Далее → Далее → Готово).

Больше ничего устанавливать не нужно.

## 2. Как запустить программу (Windows)

1. Откройте папку с программой.
2. Дважды щёлкните по файлу **`start-windows.bat`**.
3. В первый раз откроется чёрное окно и напишет «устанавливаем зависимости» —
   это займёт несколько минут, дождитесь окончания. В следующие разы запуск
   будет быстрым (несколько секунд).
4. Автоматически откроется браузер со страницей программы. Если не открылся —
   зайдите по адресу **http://localhost:3000** в любом браузере (Chrome,
   Edge, Яндекс Браузер).
5. Чтобы закрыть программу — просто закройте чёрное окно (или нажмите в нём
   Ctrl+C).

Если у вас не Windows (Mac/Linux), откройте терминал в папке программы и
выполните по очереди:

```
npm install
npm run build
npm start
```

Затем откройте http://localhost:3000 в браузере.

## 3. Где хранятся ваши данные

Все расчёты, справочник услуг и настройки хранятся в одном файле:

```
data/legal-pricing.db
```

Он лежит прямо в папке программы. Ничего никуда не отправляется — файл
остаётся только на вашем компьютере.

**Резервные копии** создаются автоматически при каждом запуске программы и
хранятся в папке `data/backups/` (последние 10 копий). Если вы удалили лишнее
или что-то пошло не так, старую копию можно найти там.

Дополнительно на странице **«Настройки»** внизу есть кнопки:
- **«Создать резервную копию»** — сделать копию прямо сейчас;
- **«Экспорт базы в JSON»** — сохранить все данные в один файл, который можно
  унести на флешке или отправить себе на почту как архив;
- **«Восстановить из файла»** — загрузить ранее сохранённый JSON-файл обратно
  (программа проверит файл перед восстановлением и не даст загрузить
  повреждённый или посторонний файл).

## 4. С чего начать работу

1. На главной странице нажмите **«Новый расчёт»**.
2. Пройдите пошаговый мастер (10 шагов): название дела, тип дела, какие
   услуги/этапы входят, сколько заседаний, нужна ли экспертиза, плановое
   время, коэффициенты сложности/срочности/ответственности, скидка, внешние
   расходы (госпошлина, экспертиза и т.д.).
3. Справа всё время видно итоговую цену клиенту, экономически обоснованную
   цену и вашу эффективную часовую ставку — обновляется мгновенно при любом
   изменении.
4. На последнем шаге нажмите **«Сохранить расчёт»**.

Дальше расчёт можно найти на странице **«Сохранённые расчёты»**: открыть,
изменить, сохранить как новую версию, дублировать, распечатать (или
сохранить как PDF) предложение для клиента, архивировать или удалить.

## 5. Справочник услуг и настройки

- **«Справочник услуг»** — список ваших услуг с ценами и плановым временем.
  Можно менять цены, добавлять новые услуги, отключать неактуальные. Важно:
  если вы поменяете цену услуги в справочнике, **старые уже сохранённые
  расчёты не изменятся** — они хранят цену на момент создания.
- **«Настройки»** — здесь задаётся ваш желаемый доход, расходы практики,
  налоговая ставка и рабочая ёмкость. На основе этого программа считает
  **целевую ставку** — ваш внутренний ориентир, сколько должен стоить час
  вашей работы, чтобы выйти на желаемый доход. Целевая ставка нигде не
  показывается клиенту и никогда не подставляется в цену автоматически —
  только как подсказка вам самим.

## 6. Если что-то не работает

- **Чёрное окно закрылось с ошибкой.** Убедитесь, что Node.js установлен
  (см. шаг 1), и запустите `start-windows.bat` заново.
- **Браузер пишет «сайт недоступен».** Значит, чёрное окно с программой уже
  закрыто. Запустите `start-windows.bat` снова.
- **Хочу перенести программу на другой компьютер.** Скопируйте всю папку
  программы, включая папку `data` — там все ваши расчёты.
- **Случайно что-то удалил(а) или испортил(а) настройки.** Откройте папку
  `data/backups/` — там резервные копии базы за последние запуски. Переименуйте
  нужную копию в `legal-pricing.db` и положите в папку `data`, закрыв перед
  этим программу.

## О программе

- Все денежные суммы считаются точно, без ошибок округления от «плавающей
  запятой» — деньги хранятся в копейках как целые числа.
- Ни один коэффициент не перемножается — только складывается, как и указано
  в вашем техническом задании.
- Скидка не уменьшает внешние расходы (госпошлину, экспертизу и т.п.) — она
  применяется только к вашему профессиональному вознаграждению.
