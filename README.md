# FIAT JUSTITIA

Одностраничный сайт юридической практики Ильи Воронова в сфере медицинского права.

## Публикация

Сайт публикуется через GitHub Pages из ветки `main`. Для локальной проверки достаточно открыть каталог через любой статический HTTP-сервер, например:

```bash
python3 -m http.server 8000
```

После этого сайт доступен по адресу `http://localhost:8000`.

## Основные файлы

- `index.html` — содержание и разметка;
- `fiat-site-v2.css` — стили и адаптивная версия;
- `fiat-site-v2.js` — заставка, меню, раскрывающиеся блоки и анимации;
- `portrait-main.jpg`, `portrait-about.jpg`, `logo.webp` — изображения сайта.
